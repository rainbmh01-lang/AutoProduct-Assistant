# Tarik AutoProduct Assistant ⚡

أداة مخصصة لطارق لأتمتة إدخال وتجهيز بيانات منتجات المتجر (WooCommerce / EdenGroupes):
1. **استخراج الاسم الدقيق والرسمي بالفرنسية** (Titre exact et complet en français).
2. **توليد الوصف التجاري والتقني بالفرنسية** (Description technique, Caractéristiques, Contenu du coffret).
3. **البحث عن أفضل الصور عالية الدقة وعرضها للاختيار** (Sélection visuelle).
4. **تنزيل الصور الثلاث المختارة بنقرة واحدة** في مجلد مخصص لكل منتج داخل `downloads/`.
5. **نسخ سريع للعنوان والوصف** بلغة HTML الجاهزة للصق المباشر في WooCommerce.

---

### طريقة التشغيل (Windows):
1. انقر نقراً مزدوجاً على الملف:
   `start.bat`
2. ستفتح الواجهة تلقائياً في المتصفح على الرابط: `http://localhost:8501`
3. أدخل اسم المنتج كما هو (مثلاً: `visseuse crown 14.4v` أو `compteuse beetro be0148`).
4. اضغط على **"Traiter le produit"**.
5. راجع الاسم، انسخ الوصف، واختر الصور الـ 3 ثم اضغط **"Télécharger les images"**.
